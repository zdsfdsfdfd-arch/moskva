# БЛИК — creative direction

> Вымышленный бренд. Все данные компании, проекты и цены — демонстрационные ориентиры для дизайна и калькулятора.

## 1. Идея

**«Мойка окон как маленький мультяшный мир».**

Окно — это интерфейс сайта. Стекло — интерактивный слой. Грязь — проблема
пользователя. Чистота — визуальный прогресс. Свет и блик — результат. Вода —
язык движения. Сгон — объект взаимодействия (курсор, слайдер, разделитель).

Пользователь не читает про мойку окон — он *моет окно вместе с персонажем*.

## 2. Бренд

**Название: БЛИК.**

Блик — это та самая белая искра на чистом стекле, которую рисуют в мультфильмах,
когда что-то стало идеально чистым. Короткое слово, легко запоминается,
отлично работает в логотипе (четырёхлучевая искра заменяет точку над «И» /
сидит на верхней перекладине «Б»), означает ровно то, что клиент покупает —
момент, когда стекло исчезает и остаётся город.

Легко заменить: имя живёт в `src/data/brand.ts`.

**Tone of voice.** Сухой, уверенный, слегка ироничный. Короткие фразы. Без
«лучших цен» и «профессионалов с 20-летним стажем». Говорим как человек, который
слишком любит чистые окна и не собирается это скрывать.

- «Окна, через которые хочется смотреть.»
- «Вот теперь видно.»
- «Без магии. Просто четыре шага.»
- «Так уже лучше.»
- «Наконец-то.»

## 3. Персонаж — Клир

Мойщик окон, который любит своё дело чуть сильнее, чем это прилично.

- **Силуэт**: грушевидное тело, крупная голова, тонкие ноги, массивные ботинки.
  Узнаваем в чёрном контуре.
- **Цвета**: мандариновый комбинезон, бирюзовая кепка и ремень, жёлтые
  резиновые перчатки.
- **Лицо**: два больших глаза разного размера, тяжёлые брови, полуулыбка-ухмылка.
- **Выражения**: `smirk` (по умолчанию), `happy`, `surprised`, `focused`, `wink`.
- **Позы**: `stand`, `clean` (рука со сгоном поднята), `sit` (сидит на раме),
  `point`, `catch` (ловит заявку сачком).
- **Поведение**: idle-покачивание, моргание, глаза следят за курсором на
  desktop, реакция на быстрый скролл (`surprised`), реакция на действия в
  before/after и калькуляторе.

Появляется в: hero-сцене (чистит стекло с люльки снаружи), before/after,
калькуляторе (реплики), how-it-works, финальном CTA (сидит на раме), футере
(сидит на букве «Б»). Не чаще.

## 4. Визуальная система

**Стиль**: original cartoon + premium web + 2.5D. Толстые контуры, cartoon
physics (squash & stretch), небольшие странные детали, мягкие рисованные тени,
лёгкое зерно поверх всего.

**Палитра** (`src/styles/tokens.css`):

| Токен        | Значение  | Роль |
|--------------|-----------|------|
| `ink`        | `#1B1F2A` | контуры, текст, ночной фон |
| `paper`      | `#F6F1E7` | фон, «бумага» |
| `cream`      | `#FFF9EE` | подоконник, карточки |
| `sky`        | `#A9E4F7` | небо, чистое стекло |
| `sky-deep`   | `#5BC3E8` | насыщенное небо |
| `tangerine`  | `#FF6B2C` | CTA, комбинезон, акцент |
| `sun`        | `#FFD23F` | блик, перчатки, солнце |
| `teal`       | `#1FB6A6` | кепка, второй акцент, ссылки |
| `grime`      | `#8C7A66` | грязь на стекле |
| `night`      | `#101A3A` | ночной город, финальный CTA |

Никаких синих градиентов клининга, никаких blobs, никакого glassmorphism.
Стекло рисуется как в мультфильмах: диагональный блик + тонкая линия отражения.

**Типографика**:

- Заголовки — *Unbounded* (широкий, плакатный, кириллица родная).
- Текст — *Onest* (нейтральный, читаемый, российский шрифт).
- Реплики персонажа — *Neucha* (рукописный, для speech bubbles).

Скругления не одинаковые: кнопки — pill, окна — 6–10px рамка с
жёсткими углами, стикеры — слегка неровные (SVG-путь с «дрожью»).

## 5. Язык анимации

- **Вода**: всё, что движется, движется как вода — spring с лёгким
  перелётом (`stiffness 220, damping 18`), капли падают с ускорением.
- **Сгон**: единственный «инструмент» — линейный, прямой ход, короткая
  остановка со squash в конце штриха.
- **Блик**: короткий scale-pop 0 → 1.2 → 1 с поворотом, всегда как награда.
- **Персонаж**: idle bob 2.4s, моргание раз в 3–5 секунд, поворот глаз.
- Scroll-driven сцены: hero-очистка, glass journey. Всё остальное — обычные
  hover/tap state'ы. Не больше двух «pinned» секций на страницу.
- `prefers-reduced-motion`: pinned-сцены показывают финальное состояние,
  marquee останавливается, частицы отключены, transitions ≤ 150ms.

## 6. Структура страницы и идея каждой секции

| # | Секция | Собственная идея |
|---|--------|------------------|
| 01 | Hero + scroll-cleaning | Одно и то же окно. Первый скролл — Клир на люльке снаружи чистит стекло полосами, грязь стирается по прогрессу скролла, город проявляется. Финал: «Вот теперь видно.» |
| 02 | Trust strip | Полоса-«сгон»: сгон на левом краю толкает бегущие факты. Без рейтингов. |
| 03 | Before / after | Разделитель — резиновое лезвие сгона. Вода стекает с лезвия, солнце становится ярче, Клир следит глазами и комментирует. |
| 04 | Услуги | Фасад дома: каждая услуга — окно на фасаде своего типа (панорама, витрина, балкон, люлька на крыше). Hover — окно играет свою мини-сцену. На мобильном фасад превращается в башню. |
| 05 | Цены | Прайс, написанный на стекле витрины. Hover по строке — сгон проходит по ней. Формат «от X ₽» + дисклеймер. |
| 06 | Калькулятор | Шаги слева, живое окно справа: площадь растит окно от одной створки до панорамной стены, доп. работы дорисовываются. Цена «считается» через spring. |
| 07 | Заявка | Разговорный сценарий: адрес → когда → телефон. Финал: Клир ловит заявку сачком. Демо-режим честно подписан. |
| 08 | Glass journey (3D) | Камера проезжает сквозь окно в мультяшный город. R3F на desktop, 2.5D слои на mobile / reduced-motion / без WebGL. |
| 09 | Как работаем | Комикс-стрип из четырёх кадров с толстыми рамками. |
| 10 | Работы | Четыре демо-объекта с мини-before/after, каждый со штампом «Демо-пример». |
| 11 | Отзывы | Честная заглушка: пустые пузыри реплик, «здесь будут реальные отзывы». |
| 12 | FAQ | Аккордеон-жалюзи: ламели открываются, впуская свет. |
| 13 | Финальный CTA | Ночь. Огромное окно, за ним тёплый город. Клир сидит на раме: «Наконец-то.» |
| 14 | Footer | Клир сидит на букве «Б». Контакты-заглушки, политика, согласие. |

## 7. Anti-template проверка

«Можно ли заменить название и использовать дизайн для стоматологии, SaaS,
агентства недвижимости или кофейни?» — Нет: окно как рамка каждой секции,
сгон как разделитель/курсор, фасад как навигация по услугам, грязь как
состояние, мойщик на люльке как главный герой. Убери текст — сайт всё равно
про окна.

## 8. Честность

- Нет рейтингов, нет отзывов, нет статистики.
- Проекты подписаны как демонстрационные.
- Цены — «от», с оговоркой о факторах стоимости.
- Форма — демо-режим, пока не подключён backend (`src/lib/leads`).
- Телефон и адрес — заглушки.
