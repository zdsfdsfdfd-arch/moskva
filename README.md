# БЛИК — мойка окон в Москве

Демонстрационный сайт вымышленной компании по мойке окон. Cartoon + premium:
окно как интерфейс, грязь как состояние, сгон как курсор, мойщик Клир как
персонаж. Москва, рубли, честные ориентиры вместо выдуманных отзывов.

Креативная концепция — в [`docs/CREATIVE_DIRECTION.md`](docs/CREATIVE_DIRECTION.md).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run lint
```

Переменные окружения — см. [`.env.example`](.env.example). Без них сайт
работает в демо-режиме: бренд вымышленный, проекты подписаны как концепты,
заявки не отправляются (пользователь видит предупреждение).

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion,
Three.js + React Three Fiber (одна ленивая 3D-сцена с 2.5D-фолбэком).
Шрифты: Unbounded, Onest, Neucha через `next/font`.

## Структура

```
src/app                 маршруты, метаданные, OG-картинка, robots, sitemap, /api/lead
src/components
  hero                  pinned-сцена: окно, Клир на люльке, очистка по скроллу
  trust                 бегущая полоса фактов
  before-after          слайдер-сгон
  services              фасад дома: услуга = окно со своей hover-сценой
  prices                прайс, заклеенный на витрине
  calculator            шаги, живое окно-превью, цена на spring, заявка
  3d                    glass journey: R3F-сцена и 2.5D-фолбэк
  process               комикс из четырёх кадров
  portfolio             демо-проекты с мини-слайдерами
  reviews               честная заглушка без отзывов
  faq                   аккордеон-жалюзи
  final-cta             ночное окно, Клир на раме
  layout                навбар, мобильное меню, футер, sticky CTA
  illustrations         Клир, город, окно, сгон, реквизит
  effects               курсор, наблюдатель скролла
  ui                    кнопки, заголовки, пузыри реплик
src/data                бренд, услуги, цены, FAQ, шаги, проекты, калькулятор
src/lib                 хуки, motion-пресеты, прайс-модель, заявки, текстуры

```

## Заявки

`src/lib/leads/submitLead.ts` — единая точка отправки. Клиент шлёт POST в
`/api/lead`; роут валидирует данные и, если настроен `LEAD_WEBHOOK_URL` или
Telegram, пересылает заявку и отвечает `mode: "live"`. Иначе — `mode: "demo"`.

## Честность

Нет рейтингов, отзывов и статистики. Цены — «от», с оговоркой о факторах.
Телефон и адрес — заглушки. Всё это меняется в `src/data`.
